# Support

Guarded Notes MCP is community-supported open-source software. Support is provided
on a best-effort basis; no response time or service-level agreement is offered.

## Start here

1. [Installation](docs/INSTALLATION.md)
2. [Usage guide](docs/USAGE.md)
3. [Troubleshooting](docs/TROUBLESHOOTING.md)
4. [Tool reference](docs/TOOLS.md)
5. [Privacy](PRIVACY.md) and [security model](docs/SECURITY-MODEL.md)

Search existing GitHub issues before opening a new one.

## Public bug reports

Use the repository's bug-report form for reproducible, non-sensitive problems.
Include:

- Guarded Notes MCP version;
- macOS version;
- Node major version;
- marketplace, local-checkout, or other MCP installation method;
- affected tool and workflow phase;
- sanitized error text; and
- reproduction steps using synthetic notes.

Replace private values with stable placeholders so the sequence remains useful.
Do not attach note contents, real titles, note/folder/account identifiers,
operation files, snapshots, manifests, authorization data, usernames, home paths,
or screenshots of a real library.

## Feature requests

Use the feature-request form and explain the user problem, proposed behavior,
privacy impact, and effect on the safety model. Requests for deletion, content
editing, network access, cross-account moves, or removal of a write gate are
outside the current scope and require a major-version design discussion.

## Security reports

Do not report a vulnerability in a public issue. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability-reporting flow.

## Scope

The project can help with the bundled server, scripts, documented Codex
marketplace packaging, and reproducible Notes automation behavior. Questions
about a third-party MCP client's account, model retention, billing, or privacy
controls belong with that client's provider.
